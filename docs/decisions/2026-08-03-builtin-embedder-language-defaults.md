# Встроенный эмбеддер и языковые дефолты

## Контекст

Курс на open source: главный барьер онбординга — эмбеддер. Без
`VOYAGE_API_KEY` и без запущенного ollama первый `session-recall index`
падал — «поставил → ошибка». Разбор того, как это решают другие OSS-проекты
с эмбеддером внутри (Chroma, Qdrant/fastembed, Continue.dev, Open WebUI):
мейнстрим — маленькая ONNX-модель в комплекте, качается при первом
использовании, работает на CPU без ключей и серверов.

## Решение

Провайдер `builtin` поверх **fastembed** + три языковых пресета, потому что
языковая специализация решает: 70MB английский специалист бьёт 220MB
универсала на английском и проигрывает на всём остальном. Язык взаимодействия
спрашивается один раз в онбординге проекта (`SESSION_RECALL_LANG` /
`settings.json`, будущая команда `setup`):

- `builtin-en` → `BAAI/bge-small-en-v1.5` (384d, ~67MB)
- `builtin-zh` → `BAAI/bge-small-zh-v1.5` (512d, ~90MB)
- `builtin-multi` → `paraphrase-multilingual-MiniLM-L12-v2` (384d, ~240MB) —
  дефолт для ru и любого другого/неотвеченного языка: никогда не ошибка.

Цепочка выбора: пресет → Voyage-ключ → пробинг локального сервера →
**builtin по языку** (вместо прежнего «voyage, который гарантированно
отвергнет»). `fastembed` — прямая зависимость: в репо extras — для
альтернатив (`openai`, `compose`), а зависимости дефолт-пути прямые
(`voyageai`); builtin — часть дефолт-пути. Кэш моделей — `DATA_DIR/models`,
потому что дефолтный кэш fastembed живёт в системном tmp, который macOS
чистит — модель перекачивалась бы.

## Что протестировали

- Каталог fastembed 0.8.0 проверен живьём: e5-small там НЕТ (не обещаем),
  bge-small-en/zh и paraphrase-multilingual есть.
- Живой кросс-языковой пруф: изолированный `XDG_DATA_HOME`, реальный
  транскрипт, `index` → русский запрос нашёл английский фрагмент со
  score 0.229 (семантика, не FTS), ранжирование корректное.
- Кэш-путь: повторный прогон скачал модель в `DATA_DIR/models` (240MB),
  системный tmp пуст.
- 36 тестов упали после смены fallback: фикстуры писались под геометрию
  voyage (1024), а import-time дефолт стал машинозависимым → пин
  `SESSION_RECALL_EMBED=voyage` в `tests/conftest.py`; цепочка выбора
  тестируется герметичными env-словарями в `test_presets.py`.

## Отвергли

- `multilingual-e5-small` — нет в каталоге fastembed; не выдумываем.
- sentence-transformers/torch — 2GB зависимостей ради дефолта.
- fastembed как extras (`[local]`) — «дефолт, который надо доустанавливать» —
  оксюморон; вес ~100MB приняли (философия Chroma).
- FTS-only дефолт без эмбеддера — «поиск тупой» как первое впечатление хуже
  честной малютки.
- Один универсальный дефолт без вопроса о языке — отвергнут Максимом:
  «просить указывать язык взаимодействия и под 3 основных языка дефолтное
  решение».
