# Session Recall landing page

The public product surface for Session Recall. It demonstrates the shared
Claude Code, Codex, and Cursor memory, the five MCP retrieval tools, the
local-first architecture, and native installation paths.

## Local development

```bash
npm install
npm run dev
npm test
```

The site is built with vinext for the Sites Cloudflare Worker runtime. It has
no database, authentication, uploads, or runtime configuration.
